**Remno Approve Bot Manager** — это мощная и удобная панель управления для вашего Telegram-бота. Она берет на себя всю рутину по работе с сервером: от установки нужных пакетов и настройки системных служб до автоматического создания бэкапов и безопасного обновления кода.

---

## 🚀 Как запустить менеджер?

Если вы запускаете установку впервые, используйте команду из официальной инструкции.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/kostiaprofrom/remno-approvebot/main/remnabotscrypt.sh)

```

После успешной установки скрипт навсегда остается в вашей системе. Теперь вы можете вызвать главное меню из любой папки на сервере, просто написав:

```bash
remnabot

```

⚠️ Важно: Скрипт требует прав администратора root для работы с системными файлами и службами.
📖 Описание функционала (Главное меню)
Главное меню состоит из пунктов управления. Рассмотрим каждый из них подробнее.
1) 🚀 Установить бота
Запускает автоматический мастер установки.
• Самостоятельно скачает нужные пакеты (Python, Git, Cron и др.).
• Создаст изолированное виртуальное окружение, чтобы не засорять сервер.
• Зарегистрирует бота как системную службу Linux (бот будет сам включаться при перезагрузке сервера).
• Создаст базовый файл настроек .env.
💡 Примечание: После установки вам нужно будет зайти в пункт «Настройки» или «Восстановление из бэкапа», чтобы бот смог подключиться к Telegram.
2) 🔄 Обновить бота (из GitHub)
Безопасное обновление бота до актуальной версии от разработчика.
• Умное сохранение: Скрипт не удалит ваши личные картинки из папки assets и базу данных bot.db. Они временно прячутся в системный кэш, а затем аккуратно возвращаются на место поверх обновленного кода.
• Пре-бэкап: Перед каждым обновлением скрипт автоматически делает резервную копию базы и настроек с пометкой update_..., так что вы никогда не потеряете данные, если что-то пойдет не так.
• Вы можете выбрать: сохранить свои текущие настройки (.env) или сбросить их на новые (из актуального шаблона разработчика).
3) ⚙️ Управление службой
Подменю для ручного контроля состояния бота:
• Запустить — включает бота.
• Остановить — полностью выключает бота.
• Перезапустить — полезно нажимать после ручного внесения изменений в файлы бота.
4) 📊 Информация (Дашборд)
Сводка о текущем состоянии системы. Здесь вы можете быстро проверить:
• Установлен ли бот и работает ли его системная служба.
• Какой Telegram-токен и Admin ID сейчас используются.
• Пути для отладки: Показывает точное расположение всех файлов бота на вашем сервере (где лежат настройки, база данных, бэкапы и системный демон).
5) 📋 Логи
Удобный инструмент для поиска ошибок и мониторинга работы бота без сложных команд:
• Live логи: Показывает действия бота в реальном времени (кто нажал старт, какие ошибки сыплются прямо сейчас). Для выхода нажмите Ctrl+C.
• Подробные логи: Открывает последние 500 строк системного журнала. В этом режиме можно скроллить текст стрелочками вверх/вниз. Для выхода нажмите клавишу q.
6) 🔧 Настройки (.env)
Меню для работы с конфигурационным файлом бота (где хранятся токены, цены, тексты и ссылки).
• Редактировать: Открывает настройки во встроенном редакторе nano. После сохранения (Ctrl+O, Enter, Ctrl+X) скрипт сам предложит перезапустить бота для применения изменений.
• Сбросить: Полностью удаляет ваши настройки и возвращает стандартные из шаблона разработчика.
7) 💾 Бэкапы и восстановление
Полноценная система резервного копирования ваших данных (настроек и базы пользователей bot.db). Все бэкапы хранятся в защищенной системной папке /opt/remno-approvebot-backups/.
• Принудительный ручной бэкап: Моментально создает копию данных (получает приставку manual_).
• Настройка автобэкапа: Позволяет включить автоматическое сохранение базы данных по расписанию (например, каждые 12 часов). • Вы сами задаете лимит хранимых копий (от 1 до 50). Скрипт будет самостоятельно удалять старые автоматические бэкапы, чтобы не забивать память сервера. Ручные бэкапы и бэкапы обновлений авто-очисткой не удаляются!
• Восстановление из бэкапа: Скрипт сам найдет все доступные бэкапы и выведет их удобным нумерованным списком (от самых свежих к старым). • Умное восстановление: Выбрав бэкап, вы можете решить, что именно вернуть — всё вместе, только базу пользователей или только настройки .env.
8) 🧨 Удалить бота
Функция полного уничтожения бота с сервера.
Останавливает службы, стирает задачи из cron, удаляет глобальную команду remnabot и полностью сносит рабочую папку бота.
🛡 Важно: Ваши бэкапы в папке /opt/remno-approvebot-backups удалены не будут, чтобы вы всегда могли развернуть бота заново без потери аудитории.
0) 🚪 Выход
Закрывает менеджер и возвращает вас в командную строку сервера.
